# CR-LBJ-Receiver · 中国铁路 LBJ 列车预警器解码程序

> 用一支几十元的 RTL-SDR，接收 821.2375 MHz 上的 LBJ 列车防护报警信号，
> 实时解出车次、机车、线路、公里标、速度与经纬度，并在地图上跟着车跑。

## 界面一览

v2.3 起是**全景式布局**：不再用页签，一屏分三段，所有内容同屏可见、互不遮挡。
v2.4 把外观换成 **Fluent Design**，「输出 1 / 输出 2」收成一条薄底栏，省下的高度全给地图。

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 文件   视图   配置   帮助                                                     │
├───────────────────────────────────────────────────────────────────────────────┤
│ [▶ 开始] [■ 停止]  频率: 821.2375 MHz   ● 已连接        [日间]  [全屏]       │
├──────────────────────────────────────────┬────────────────────────────────────┤
│                                          │ 当前解码 / 历史记录                │
│                                          │ 时间 车次 方向 速度 公里标 … 报文  │
│          实时位置（高德地图）            ├────────────────────────────────────┤
│              约六成宽度                  │ 列车信息                           │
│            （高德 JS API）               │ 车次 方向 速度 公里标 机车 线路 …  │
│ [夜间] [中心] [跟随] [清除] [网页]       │                                    │
├────────────────────┬─────────────────────┴──────────────┬─────────────────────┤
│ 接收频谱   [图形▾] │ 车次信息                           │ 机车信息            │
│  ~~~──~──~──       │ 12306 结果 / 查看时刻表            │ 机型 / 牵引参数     │
├────────────────────┴────────────────────────────────────┴─────────────────────┤
│ ● 16:04:35 [解码] G1234 下行 82 km/h │ ⚠ AFC 置信度偏低                      │
│                                      │ 信号 -63 dB · AFC 0.06 · 门控 ON      │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

所有分隔线都能拖；`F11` 全屏、`Ctrl+L` 看完整日志、`Ctrl+D` 开运行状态仪表板、
`Ctrl+T` 切换日/夜配色。

**三段各放什么**：

| 位置 | 内容 | 说明 |
|---|---|---|
| 上段左 | 实时地图 | 约六成宽，按方向着色、轨迹折线、点击看不透明信息卡片；底图跟随界面日/夜 |
| 上段右 | 当前解码 / 历史记录 + 列车信息 | 两张表在上（**列完全一致**），字段卡片在下；窗口矮时字段名自动收起只留值 |
| 中段 | 接收频谱（含「图形/终端」切换）｜车次信息｜机车信息 | 三块并排，比例 5 : 3 : 3 |
| 底栏 | 输出 1 · 最新一条日志 ｜ 输出 2 · 一句话状态 | 一条薄底栏，各占一半；字比别处大一档，放不下自动省略 |

**输出 2** 只给一句话结论：正常就是「接收正常」，有问题就直接说原因——「AFC 置信度偏低」
「信号偏弱」「频偏 +180 Hz」「干扰偏多 7 次」，下面一行小字补当前读数；点整块打开运行状态仪表板。

## 功能

**接收与解码**

- 821.2375 MHz，POCSAG 1200 bps，BCH(31,21) 单比特纠错，同步字容错 ≤2 bit
- 全字段解析：车次（含前缀）、机车号/代号、线路、公里标、方向、速度、**经纬度**、报文类别
- 四种数据源，可保存多套随时切换：本机 USB 直连（ctypes 调 librtlsdr，不经过 TCP）、本机 USB 经 rtl_tcp 中转、局域网/本地 RTL-TCP、OpenWebRX
- **一站式启动**：`rtl_tcp.exe` / `rtlsdr.dll` 等随包内附，装完驱动插上棒子点「开始」就能收
- **重复报文合并**：同一次广播的多帧只留最优一条，列表、地图、历史库都不再堆重复行

**界面与交互**

- **中国铁路标准配色**：CR 红 `#DA291C`（Pantone 485C）+ CR 蓝 `#003DA5`（Pantone 286C），
  夜间 / 日间 / 跟随系统三档主题，**`Ctrl+T`（视图菜单）即时切换、无需重启**，
  全部面板、地图、图表统一取色
- **运行状态仪表板**（`Ctrl+D`）：48 项指标一屏看完，每秒刷新，可复制全部用于求助
- **输出 2 · 接收状态**：一句话说清当前状况（「接收正常」/「AFC 置信度偏低」/「信号偏弱」…），
  下面一行小字附信号、AFC、门控读数，点一下直通仪表板
- **Fluent Design 外观**：控件来自 [qfluentwidgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)
  （GPLv3），圆角卡片、悬停动画、深浅色一体；`cr_lbj/ui/widgets.py` 只做封装，缺库时自动退回原生外观
- **自适应布局**：窗口或屏幕变化时自动调分栏比例、字段列数、标题显隐，不必手拖
- **字号按屏幕分档**：小屏 / 笔记本 / 中屏 / 大屏四档，底栏大字另有四档（15 / 17 / 19 / 21 px），
  不再出现「4K 屏上还是 12 px」的情况
- **配置分页**：数据源配置 / 射频设置 / 到达估算 / 地图与车次 / 解码与界面 / 外观主题
- 全景式布局：上段「地图 +（当前解码/历史记录、列车信息）」，中段「频谱 | 车次 | 机车」，底栏两条输出
- **实时地图**：高德 JS API 2.0，按方向着色、轨迹折线、点击看不透明信息卡片，
  车多时自动避让重叠标记（隐藏副行 + 降透明度），**夜间/日间一键切换，且默认跟随界面主题**
- **输出 1 · 日志**：只显示最新一条（大字、按级别着色），点一下（或 `Ctrl+L`）打开实时日志窗口
- **全屏模式**：`F11` 切换，`Esc` 退出，全屏自动隐藏菜单栏
- **分辨率自适应**：按屏幕尺寸自动选 0.92~1.25 倍缩放，也可手选 85%~150%，字号/行高/按钮一起缩放
- **触屏友好**：惯性滚动、加宽滚动条与分隔条，Surface 等设备上手即用

**数据与查询**

- 历史留档：SQLite 本地库（含经纬度与唯一 `uid`），同一条记录被更优报文替换时原地更新
- 导出 CSV（UTF-8 with BOM，18 列，Excel 双击不乱码）
- 2026 车次规则：X/G/T/K/D/C/S/Z/N/V/B/DH/DJ 新字头，自动兼容 2014 旧规则
- ETA 到达估算（按本站公里标 + 速度）、12306 时刻表查询（按报文类别智能判断可查性）、机车技术参数

## 快速开始

### 1. 装驱动（一次性）

Windows 下 RTL2832U 默认是 DVB-T 电视棒驱动，必须换成 WinUSB：

1. 插上 RTL-SDR；
2. 打开 [Zadig](https://zadig.akeo.ie/) → `Options → List All Devices`；
3. 选中 `Bulk-In, Interface (Interface 0)`（VID `0BDA` / PID `2838`）；
4. 目标驱动选 **WinUSB**，点 `Replace Driver`。

> 驱动不能随包分发，这一步只能在你自己机器上做。用过 SDR#、rtl_tcp 的通常已经就绪。

### 2. 选数据源

打开程序 →「配置 → 配置...」（`Ctrl+,`）→「数据源配置」页：

- 棒子插在本机 → 选 **本机 RTL-SDR (USB 直连)**（默认就是它，打不开会自动退回中转）
- 连局域网/本机的 rtl_tcp → 选 **局域网 / 本地 RTL-TCP**，填地址端口
- 连 OpenWebRX → 选 **OWRX**（注意 DC 偏移要设 0）

「检测设备」会读出 tuner 型号并推荐采样率/增益，一键应用。

### 3. 开始接收

点菜单栏右侧的「接收」开关（或视图 → 开始接收，`Ctrl+R`）。「● 未连接」会变成「● 已连接」，底栏右侧的状态提示开始显示信号 dB 值
（点它可打开运行状态仪表板看全链路指标）；
收到报文后「当前解码」出现记录，地图上出现标记，机车卡片被填满。

> 车少的路段可能十几分钟没有任何报文，这不是程序坏了。
> 只发基础帧的车次没有经纬度、不会上地图，也属正常（详见用户手册 6.1）。

### 可选：打开地图

「配置 → 地图与车次」页填入高德 **Web端(JS API)** 的 Key 与安全密钥即可。
不填也能正常解码、看列表、查历史，只是地图区域会提示未配置。

## 运行与构建

### 从源码运行

```bash
pip install PySide6 PySide6-Addons pyqtgraph numpy scipy PySide6-Fluent-Widgets
python main.py
```

- Python 3.10+（已在 3.14 上验证）
- 必须装 **PySide6-Addons**（内嵌地图要 QtWebEngine）；只装 Essentials 也能跑，但地图会降级为提示面板
- 外观需要 **PySide6-Fluent-Widgets**（导入名 `qfluentwidgets`，GPLv3）；
  没装也能跑，只是界面退回原生 Qt 样式，`build.py` 会在打包前提醒
- 源码运行时 `rtl_tcp.exe` 放在项目根的 `tools/rtl/` 即可被自动找到（也兼容 `RTL_TCP_Server/` 与 `PATH`）

### 一键构建

```bash
python build.py                 # 清理 → 打包 → 清历史库 → 校验 → 汇总（配置保留）
python build.py --no-clean      # 跳过前置清理，增量构建更快
python build.py --keep-data     # 连历史库也保留
python build.py --reset-config  # 连 dist/lbj_config.json 一起清掉（回到首次运行状态）
```

> 打包**不会动** `dist/lbj_config.json`——高德 Key、数据源、主题都在里面，
> 每次重打包都清掉等于让你重填一遍。要重置才加 `--reset-config`。

产物：`dist/CR-LBJ-Receiver.exe`（单文件，约 283 MB），以及 `dist/README.md` 与 `dist/docs/`。

`SDR_LBJ.spec` + `build.py` 负责把 RTL 工具、四份文档一并带进产物，剔除无关依赖
（单文件从 575 MB 降到 283 MB），并在构建后清理过程文件，交付目录保持干净。

> 源码仓库默认**不保留** `dist/` / `build/` / `__pycache__` 等构建产物，需要 EXE 时
> 执行 `python build.py` 重新生成。含高德 Key 的本机配置请另存为
> `lbj_config.local.json`（已在 `.gitignore` 中，不入库）；程序读取的是项目根的
> `lbj_config.json`。

```
CR_LBJ_Receiver/
├── main.py                     程序入口（源码运行 / 打包共用）
├── cr_lbj/                     应用包
│   ├── runtime.py              共享运行时：路径 / 常量 / 缩放 / 控件别名
│   ├── gui.py                  GUI 组装层
│   ├── app.py                  启动层（参数 / 配置 / 主题 / QApplication）
│   ├── core/                   内核：decoder.py（DSP/解码）、usb_direct.py（USB 直连）、
│   │                           source_stats.py（诊断口径）、rtl_paths.py（文件定位）、bridge.py
│   ├── data/                   数据：loco_info.py（车型表）、history.py（SQLite）
│   ├── ui/                     界面：theme.py / widgets.py / map_panel.py
│   │   ├── components/         频谱、基础组件、信息面板、历史面板、车次查询
│   │   ├── dialogs/            详情、配置、日志、帮助对话框
│   │   └── windows/            main_window.py（主窗口 + 状态仪表板）
│   └── utils/                  通用纯函数 helpers.py
├── build.py / SDR_LBJ.spec     构建脚本与打包配置
├── lbj_config.json / 国铁.ico / LICENSE / README.md
├── docs/                       四份文档（含 架构说明.md）
├── tools/rtl/                  随包分发：rtl_tcp / rtl_test / rtlsdr.dll
└── dist/                       构建产物：EXE + README + docs
```

运行时还会在同目录生成 `lbj_config.json`（首次运行的默认配置）与 `history.db`（历史库）。

## 常见问题

**需要联网吗？**
解码不需要。只有地图瓦片/脚本、12306 时刻表需要联网；机车参数已内置在程序里，
查「机车详情」不需要联网（v2.5 起移除了机车图片区域）。

**能收多远？**
取决于天线与地形。车载 LBJ 功率有限，通常几公里内；高架天线 + 好馈线可到十几公里。

**为什么以前一秒刷四五行，现在只有一行？**
v2.1 起做了择优合并。想逐帧看，把「配置 → 解码与界面 → 重复报文合并」设为 0。

**为什么有的车没有经纬度 / 不上地图？**
只有扩展长报文（1234002 / 1234001）带经纬度，且要与基础帧在 5 秒内配对成功。
只发基础帧的车次没有坐标，这是报文本身没有这个信息，不是解码错误。

**界面字太小 / 太大？**
默认「自动」：按屏幕尺寸分四档（0.92 / 1.00 / 1.12 / 1.15 / 1.25），大屏自动放大。
想固定就在「视图 → 界面缩放」里挑一档，重启生效。
注意：选「100%」等同于「自动」——老版本把 100% 当默认值写进配置，等于把自动缩放关掉了，
v2.4 起不再这样处理。

**两个显示器缩放不一样，窗口拖过去被裁 / 字忽大忽小？**
v2.5 起窗口按**所在屏**的可用区自动收紧，换屏会重新排布三段比例；两屏共用同一套
逻辑布局，物理大小交给系统按各自 DPI 渲染。副屏是 200% 缩放时窗口会比主屏小一圈，
但内容完整、不会溢出屏幕。

**界面太暗 / 想换浅色？**
「视图 → 外观主题」选「日间」，或选「跟随系统」让程序跟着 Windows 的浅色/深色设置走，
也可在「配置 → 外观主题」页设置。主题需要重启程序生效。

**想看更细的运行指标（信号、AFC、门控、去重…）？**
按 `Ctrl+D`，或直接点底栏右侧那块状态提示，打开「运行状态仪表板」，48 项每秒刷新。

**底栏右边那句是什么意思？**
它只说最要紧的一件事：「接收正常」就是一切都好；否则直接说原因——
「AFC 置信度偏低」「信号偏弱」「频偏 +180 Hz」「干扰偏多 7 次」「链路已断开」。
下面一行小字是当前的信号 / AFC / 门控读数。

**地图上车一多，标签就挤在一起？**
v2.2 起自动避让：放不下的标记会隐藏速度/公里标副行并变淡，放大或散开后自动恢复正常；
点任意标记可看不透明信息卡片（含轨迹点数与里程）。

**普速车次查不到时刻表？**
先看「车次信息」卡片给出的类别。客运类（动车组、城际、市郊、旅游、普速、直达特快）都可查；
货运（含直达/班列/快运）、单机、回送、检测、路用等 12306 上本来就没有时刻表。
v2.2 已修复「普速旅客列车、普通旅客快车/慢车被误判为不可查询」的问题。

**能在 Linux / 树莓派上跑吗？**
源码可以。QtWebEngine 在部分 ARM 发行版需要额外依赖，缺它时地图降级为提示面板。

更多问题见 [用户手册 · 故障排查](docs/用户手册.md) 与 FAQ。
