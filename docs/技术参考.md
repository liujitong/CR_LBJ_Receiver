## 1. 信号与帧结构

| 项 | 值 |
|---|---|
| 频点 | 821.2375 MHz |
| 调制 | 2FSK（FSK 频偏约 ±2.4 kHz） |
| 速率 | 1200 bps |
| 编码 | BCH(31,21)，生成多项式 g(x)=x¹⁰+x⁹+x⁸+x⁶+x⁵+x³+1（0x369） |
| 帧同步 | POCSAG 同步字，容错 2 bit |
| 同步字 | `SYNC_STD=2094142936`、`SYNC_INV=2200824359`、`IDLE_WORD=2055848343` |
| 比特极性 | 反逻辑（DPLL 输出取反） |

每帧由 32 bit 码字组成：1 bit 标志位 + 11 bit 控制字段 + 20 bit 数据（5 个 BCD 字符，4 bit 反序传输）。

### 报文类型判定

| 类型 | 地址 | BCD 长度 |
|---|---|---|
| 短报文 | 1233999 / 1234000 | ≥ 15 |
| 合并报文 | 1233999 / 1234000 / 1234002 | ≥ 65 |
| 独立长报文 | 1234001 / 1234002 | < 65 |
| 无效 | 1234008 | 丢弃 |

功能码 `func`：`1` = 下行，`3` = 上行，其余记为未知。

## 2. 解调链路

```
u8 IQ (240k/960k S/s)
  → 直流/正交校正（IqCorrector，默认 DC 偏移 50 kHz）
  → 半带抽取 ×2
  → 信道 FIR（35 kHz 带宽）
  → FM 鉴频（FmDiscriminator）
  → AFC 环路（上限 8 kHz，增益 0.45）
  → RSSI 门控（阈值 -55 dB，迟滞 4.0 dB，保持 700 ms）
  → DPLL 位同步（1200 baud）
  → BCH(31,21) 单比特纠错
  → POCSAG 帧同步
  → 报文解析
```

### DPLL 参数

| 参数 | 值 | 说明 |
|---|---|---|
| 迟滞 | 0.03 | 归一化幅度迟滞 |
| 积分步长限制 | `ncoStep × 0.02` | 相位积分器限幅 |
| 积分增益 | 0.005 | |
| 比例增益 | 0.1 | |
| 峰值衰减 | 0.0005 | 自适应幅度跟踪 |
| 迟滞上下限 | 0.006 ~ 0.15 × amp | |

### RSSI 门控

| 参数 | 默认值 |
|---|---|
| 打开阈值 | -55 dB |
| 迟滞 | 4.0 dB |
| 保持时间 | 700 ms |
| 确认块数 | 1 |

门控状态：`OFF` / `ARM` / `ON` / `HOLD` / `BYPASS`。信号释放后复位 DPLL 与帧同步状态。

## 3. 报文解析

### 短报文（车次、方向、速度、位置）

| 字段 | BCD 位置 | 说明 |
|---|---|---|
| 车次 | 0–5 | 字母数字；非字母数字判为无效（计干扰） |
| 方向 | 功能码 | 1 下行 / 3 上行 |
| 速度 | 6–8 | 0–400，超出记 `---` |
| 位置（公里标） | 10–14 | 格式 `DDDD.D`，含 `* - X U` 记 `---.-` |

### 长报文（线路、机车、经纬度）

| 字段 | 位置 | 说明 |
|---|---|---|
| 线路名 | GBK 解码 | 126×190 GBK 表，校验线路名合法性 |
| 机车代号 | 20 bit | 查 141 项代号表 → 车型名 |
| 经度 | 30–38 | `DDD + MM.MMMM`，范围 70–140 |
| 纬度 | 39–46 | `DD + MM.MMMM`，范围 0–60 |

### 车次分类

按车次前缀与速度分段判定等级（高速动车组 / 动力集中动车组 / 城际 / 市郊 / 快速 / 普通快车 / 慢车等）。分类规则在 2027-01-01 前后采用不同分段，切换由系统日期自动驱动。

### 去重

同一车次在去重窗口（默认 2.5 s）内只保留质量最高的一条：详细报文优先 > 有坐标优先 > 无 BCH 错优先 > RSSI 高优先。更优记录沿用同一 uid，UI 就地替换。

## 4. 频谱与瀑布

| 项 | 值 |
|---|---|
| FFT 点数 | 1024（Hanning 窗） |
| 频谱分辨率 | 256 bin（1024 点分箱后取每箱最大值） |
| 平滑 | 一阶 IIR，0.75 旧 + 0.25 新 |
| 瀑布行数 | 220（约 25 fps） |
| 色标 | Google Turbo 多项式近似 |
| 动态范围 | 5% / 99.5% 分位裁剪 + 对数压缩（强度 2.0） |

Android 端状态帧通过双缓冲共享内存上报（1104 字节 / 276 word），每 40 ms 轮询一次。

---

## 5. 到达时间估算

由公里标、线路名、方向与速度估算到本站的剩余距离与耗时。本站公里标由用户配置，线路公里标表支持增量维护。数据不足或速度异常时显示 `等待信号`。
