## 1. 系统要求

| 项 | 要求 |
|---|---|
| 系统版本 | Android 8.0（API 26）及以上 |
| CPU 架构 | `arm64-v8a`（推荐）、`armeabi-v7a`、`x86_64` |
| 存储 | 约 20 MB（不含地图缓存） |
| USB 宿主 | 使用 USB 直连时需要 OTG 支持与足够供电 |
| 网络 | 地图、车次查询、OWRX / RTL-TCP 数据源需要网络 |

三个架构使用同一份 Kotlin 与 C++ 代码，功能完全一致，不存在"精简版"。

## 4. 数据源

与桌面端相同的三种类型：USB 直连、RTL-TCP、OWRX。

- 支持保存多套数据源配置，随时切换；
- 切换类型时显示推荐采样率与增益；
- 从子页返回时询问是否保存，可另存为新配置；
- 已保存配置可重命名、删除。

### USB 直连

首次连接会弹出系统 USB 授权对话框。程序通过 `VID 0x0BDA` 匹配 RTL-SDR 设备，读取 tuner 型号（R820T2 / R828D / E4000 等）并推荐可用的采样率与增益档位；「检测设备」可读取 tuner 型号与增益列表。

部分机型限制 USB 安装/调试，安装或访问设备失败时：

1. 解锁屏幕并保持亮屏；
2. 设置 → 更多设置 → 开发者选项 → 打开「USB 安装」「USB 调试（安全设置）」；
3. 或改用「把 APK 传到手机点击安装」的方式。

## 5. 与桌面端的差异

| 项 | 说明 |
|---|---|
| 界面 | Compose 单页应用，底部导航；桌面端为多面板窗口 |
| 历史存储 | Room 数据库；桌面端为 SQLite 文件 |
| 地图缓存 | DiskLruCache（原生代拉瓦片）；桌面端为浏览器 IndexedDB |
| 配置存储 | SharedPreferences（JSON）；桌面端为 `%LOCALAPPDATA%` 下的 JSON |
| 频谱 | 状态帧 40 ms 轮询（约 25 fps）；桌面端 30 fps 定时器 |
| 定位 | 使用系统最后已知位置，不主动开启 GPS |

除此之外，解码参数、报文解析、地图页面、数据表、关于信息全部共享，行为一致。

## 7. 已知限制

| 限制 | 原因 |
|---|---|
| 部分手机 OTG 供电不足导致采样中断 | USB 供电能力；建议使用带供电的 OTG 集线器 |
| 高采样率下偶有丢块 | CPU 实时性；可在设置中降低采样率或块大小 |
| 后台运行受系统省电策略限制 | Android 后台限制；前台运行时最稳定 |
| 长时间运行内存增长 | 地图缓存与历史记录会累积；可清理缓存或设置缓存上限 |
