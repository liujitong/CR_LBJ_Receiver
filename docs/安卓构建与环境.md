## 2. 构建命令

```powershell
cd android
.\gradlew.bat :app:assembleDebug      # 4 个 ABI（含 x86_64，供模拟器）
.\gradlew.bat :app:assembleRelease    # 3 个 ABI，需 keystore.properties
.\gradlew.bat :app:testDebugUnitTest  # 单元测试
```

产物：`android/app/build/outputs/apk/{debug,release}/`。

## 3. 常见问题

### KSP 报 "this and base files have different roots"

Gradle 缓存里残留了上一次构建的绝对路径（例如用 `subst` 挂载到其它盘符测试后）。
清理：

```powershell
.\gradlew.bat --stop
Remove-Item -Recurse -Force app/build/kspCaches, app/build/kotlin, .kotlin, .gradle/configuration-cache
```

### 中文路径导致 ninja 失败

旧版 ninja（<1.12）用 ANSI 代码页解释路径，仓库路径含中文时报
`FindFirstFileExA(...): 文件名、目录名或卷标语法不正确`。
处理：把 ninja ≥1.12 放到 `cmake.dir/bin/` 下（`tools/fix_ninja.ps1`），或把仓库放到纯 ASCII 路径。

### 单元测试找不到 Android 类

单元测试用 Robolectric 或纯 JVM 断言；涉及 Android 框架的测试需在 `src/test` 下配置。
