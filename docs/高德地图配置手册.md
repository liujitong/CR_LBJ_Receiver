# 高德地图配置与开发手册（CR-LBJ-Receiver v2.5）

本手册分两部分：

1. **使用**：在程序里配置高德 Key，让地图显示列车位置，并在夜间/日间配色间切换。
2. **开发**：高德 JS API 2.0 的标注方法（Marker / InfoWindow / Polyline / setMapStyle），
   标注防重叠、信息卡片、轨迹抽稀的实战写法，以及本程序与地图页面的数据协议，方便你二次开发。

> v2.2 的地图侧改动：标记按屏幕坐标自动避让（叠不下就缩成单行并变淡）、
> 信息窗改为不透明卡片、轨迹改为「移动 >6 m 或 间隔 >3 s」抽稀最多 240 点、
> 配色统一取自 `theme.py` 的中国铁路标准色。对应章节：3.1、4.3、4.4、4.8。
> v2.3.1 的地图侧改动：默认中心改成**地名 + 地理编码**（不再默认北京、不加标记）、
> 手动拖图即暂停自动跟随（`userTouched`）、标记下方加精确点位小球，
> 并修掉 `Marker.getZIndex()` 不存在导致刷新流程中断（表现为「来车后地图不动」）的缺陷。

## 一、先搞清楚：经纬度从哪来

| 报文 | 地址 | 是否含经纬度 |
|---|---|---|
| 基础帧（车次/速度/公里标） | 1234000、1233999 | 否 |
| 时间广播 | 1234008 | 否 |
| 扩展长报文（机车/线路/经纬度） | 1234002、1234001 | **是** |

- 长报文里经度是 **3 位度 + 6 位分**，纬度是 **2 位度 + 6 位分**，单位是“度分”，不是十进制度。
- 本程序已换算为十进制度，字段为 `longitude` / `latitude`，坐标系 **WGS-84**。
- 只有“基础帧 + 长报文”配对成功（5 秒内）才会得到完整记录，地图上才会出现该车。
- 部分线路/车次只发基础帧，这类车不会出现在地图上，属于正常现象。

程序在落点前会自动做 **WGS-84 → GCJ-02** 纠偏（高德底图使用 GCJ-02），详情窗口仍显示原始 WGS-84 坐标。

## 二、申请高德 Key

1. 打开 <https://console.amap.com/dev/key/app>，注册/登录。
2. 「应用管理 → 我的应用 → 创建新应用」，名称随意（如 `CR-LBJ`）。
3. 点击「添加 Key」：
   - **Key 名称**：`cr-lbj-desktop`
   - **服务平台**：必须选 **Web端(JS API)**
   - 勾选同意条款，提交。
4. 创建后会得到两个值：
   - **Key**：形如 `1a2b3c4d5e6f...`
   - **安全密钥（securityJsCode）**：形如 `a1b2c3d4...`（2021-12 之后申请的 Key 必须配合使用）

> 注意：不要选“Web服务”。Web服务 Key 用于静态图/路径规划等 REST 接口，不能加载 JS 地图；两者额度也分开计算。

## 三、在程序里配置

1. 打开程序 →「配置 → 配置...」（`Ctrl+,`）。
2. 切到「地图与车次」页：
   - **高德 Key**：粘贴 Key
   - **安全密钥**：粘贴 securityJsCode
   - **默认中心**：填一个**地名**（如 `南昌站`、`杭州东站`），不用经纬度；
     启动时用地理编码把它解成坐标后把视图挪过去，**不会加任何标记**。留空 = 全国概览
     （旧版硬编码的北京 `[116.397, 39.909]` 已取消）
   - **默认缩放**：建议 10~13
   - **自动跟随最新列车**：勾选后自动把视野移到最新报文位置
     （手动拖一下地图就会自动取消勾选，见 4.5）
   - **显示历史轨迹**：勾选后为该车画折线（最多 240 个抽稀点，见 4.4）
   - **地图夜间模式（深色底图）**：默认跟随界面主题（v2.4），见 3.1
3. 确定并保存。地图 Key 变更会立即重建页面，无需重启 DSP。

上段左侧「实时位置」卡片就是地图：点击标记弹出**不透明信息卡片**（车次、时间、方向、速度、
公里标、线路、机车、类别、轨迹点数与里程、坐标），卡片右上角可关闭。

> 若只看到“尚未配置高德地图 Key”，说明 Key 为空；若提示“脚本加载失败”，看第七节排查。

### 3.1 夜间 / 日间配色

v2.1 提供两套高德官方样式，切换即时生效（调 `map.setMapStyle()`，不重建页面，
标记与轨迹原样保留）：

| 模式 | 样式名 | 适合场景 |
|---|---|---|
| 夜间（默认） | `amap://styles/darkblue` | 与程序深色主题统一，夜间值守不刺眼 |
| 日间 | `amap://styles/normal` | 白天强光、投影演示、截图写文档 |

三种切换入口（效果一致，选择写入 `lbj_config.json` 的 `mapNight`）：

1. 地图卡片左上角「夜间 / 日间」按钮（按钮文字是**目标**模式）；
2. 菜单「视图 → 地图夜间模式」；
3. 配置窗口「地图与车次 → 地图夜间模式（深色底图）」。

> **v2.4 起地图底图默认跟随界面主题。** 切「日间」，高德底图也变日间；切回「夜间」，
> 底图变深色——不会再出现「浅色界面配深色地图」的割裂感。上面三个入口仍可单独微调，
> 但下一次切换界面主题时会重新对齐。实现见「技术参考 9.7」的 `_syncMapNight()`。

> **界面主题与地图样式的关系**：「视图 → 外观主题」控制程序界面（夜间/日间/跟随系统，
> 用中国铁路标准色 CR 红 `#DA291C` / CR 蓝 `#003DA5`），`mapNight` 控制高德底图——
> 现在两者由 `_syncMapNight()` 保持一致，配置字段仍是分开的两个（`theme` / `mapNight`）。
> 标记的上行/下行颜色由 `theme.py` 的 `mapColors()` 统一给出，切换界面主题后标记会跟着变。

高德还提供若干付费/免费样式（`amap://styles/whitesmoke`、`grey`、`graffiti`、
`macaron`、`blue`、`dark`、`fresh`、`darkblue`、`wine`），想换配色改
`map_panel.py` 里的 `STYLE_DAY` / `STYLE_NIGHT` 两个常量即可，注意部分样式需要
在高德控制台额外开通。

### 4.2 添加车次标记（自定义外观）

```js
const marker = new AMap.Marker({
  position: [lon, lat],          // 注意顺序：先经度，后纬度
  anchor: 'bottom-center',
  content: buildMarker('K19533', '下行', '67 km/h'),
  zIndex: 120
});
map.add(marker);
```

`content` 可以是 DOM 元素，比默认图标更灵活：

```js
function buildMarker(train, direction, speed) {
  const el = document.createElement('div');
  // 不要再写 transform:translate(-50%,-100%)：anchor:'bottom-center' 已经做过偏移，
  // 两者叠加会让标记飘到坐标左上方
  el.style.cssText = 'text-align:center;white-space:nowrap;font:12px sans-serif';
  const tag = document.createElement('span');
  tag.textContent = (direction === '下行' ? '▼ ' : '▲ ') + train;
  tag.style.cssText = 'display:inline-block;padding:3px 7px;border-radius:4px;' +
    'background:' + (direction === '下行' ? '#00e08a' : '#5599ff') +
    ';color:#07110b;font-weight:700';
  const sub = document.createElement('span');
  sub.textContent = speed;
  sub.style.cssText = 'display:block;background:rgba(8,14,20,.82);color:#d8e6f2;' +
    'font-size:10px;border-radius:3px;padding:1px 4px';
  el.appendChild(tag); el.appendChild(sub);
  return el;
}
```

> 定位方式二选一：要么 `anchor:'bottom-center'` 配不带 `transform` 的 `content`，
> 要么 `content` 自己 `translate(-50%,-100%)` 且不设 `anchor`。混用必偏。

更新位置时**不要**反复 `new Marker`，复用实例：

```js
marker.setPosition([newLon, newLat]);
marker.setContent(buildMarker(train, direction, speed));
```

### 4.4 轨迹折线

```js
const line = new AMap.Polyline({
  path: [[lon1, lat1], [lon2, lat2]],   // 至少两个点
  strokeColor: '#DA291C',               // 跟随上/下行
  strokeWeight: 4,
  strokeOpacity: 0.72,
  lineJoin: 'round',
  showDir: true                          // ≥3 点时显示方向箭头
});
map.add(line);
line.setPath(newPath);   // 后续更新
```

**点不能无脑往里堆。** 车停站时每秒一帧报文会产生一堆几乎重合的点，既浪费带宽又让折线发毛。
本程序的抽稀规则（`map_panel.updateTrain()`）：

| 条件 | 阈值 | 作用 |
|---|---|---|
| 位移 | `> 6e-5` 度（约 6 m） | 停站时不记录 |
| 或时间 | `> 3 s` | 即使不动也留一个心跳点 |
| 上限 | 240 点 | 超出后 `del path[:-240]` 滑窗丢弃最早的 |

累计里程按平面距离估算（`111 km/度`），只用于信息卡片里那句「x.x km」，
不做精确里程统计。

### 4.5 视野跟随（别把用户的手"抢"回来）

```js
// 单车：直接定位
map.setZoomAndCenter(13, [lon, lat]);

// 多车：自动框选
map.setFitView(markers, false, [50, 50, 50, 50], 14);
```

**这一节有个坑，务必按下面写。** 如果你的刷新循环（每 250 ms 一帧）里无条件调
`setZoomAndCenter`，用户手指刚落下就被拉回去，表现为"地图动不了"。
正确做法是「只在车真的动了才跟随」+「认人的手势」：

```js
var userTouched = false, lastAuto = null;

map.on('mousedown',  function () { userTouched = true; });
map.on('touchstart', function () { userTouched = true; });
map.on('mousewheel', function () { userTouched = true; });
// 程序调 setZoomAndCenter 不会触发上面三个事件，所以自动跟随不会把自己锁死

function follow(a) {                    // a: 最新一列车
  if (userTouched) { return; }          // 用户正在手动看，别抢
  var moved = !lastAuto ||
    (Math.abs(a.lon - lastAuto[0]) + Math.abs(a.lat - lastAuto[1])) > 3e-4; // ≈30 m
  if (moved) {
    lastAuto = [a.lon, a.lat];
    map.setZoomAndCenter(13, [a.lon, a.lat], false, 300);
  }
}

// 用户点"恢复跟随"时
function reFollow() { userTouched = false; lastAuto = null; }
```

> 高德 2.0 的 `Marker` **没有 `getZIndex()`**，只有小写 z 的
> `getzIndex()` / `setzIndex()`。在 `declutter()` 之类的避让逻辑里误用
> `getZIndex()` 会抛 `mk.getZIndex is not a function`，把整个刷新流程打断
> ——看起来就是"来车之后地图再也不动了"。自己的 zIndex 和 DOM 元素最好单独存一份。

### 4.5.1 默认中心：地名 → 坐标（Geocoder，不加标记）

```html
<script src="https://webapi.amap.com/maps?v=2.0&key=KEY&plugin=AMap.Geocoder"></script>
```

```js
var ADDR = '南昌站';                    // 用户填的地名
var CACHE = [0, 0];                     // 上次解析结果，断网兜底

function resolveCenter(cb) {
  if (!ADDR) { cb && cb(false); return; }
  // Geocoder 是异步按需加载的插件，直接 new 可能还没注入
  AMap.plugin('AMap.Geocoder', function () {
    var geo = new AMap.Geocoder({ city: '全国', citylimit: false });
    geo.getLocation(ADDR, function (status, result) {
      if (status === 'complete' && result.geocodes.length) {
        var loc = result.geocodes[0].location;   // ★ 已是 GCJ-02，不用再纠偏
        CACHE = [loc.lng, loc.lat];
        map.setZoomAndCenter(12, [loc.lng, loc.lat]);   // 只挪视图，不建 Marker
        cb && cb(true, loc);
      } else {
        cb && cb(false);                     // 解析失败：保持原视野
      }
    });
  });
}
```

要点：

| 要点 | 说明 |
|---|---|
| `plugin=AMap.Geocoder` | 只在 URL 里列出还不够稳，`AMap.plugin()` 回调里再 `new` 最保险 |
| 返回值坐标系 | `geocodes[0].location` 直接就是 **GCJ-02**，不要再转一次 |
| 不要加 Marker | 需求只是"把视图挪过去"，加标记反而会被误认为列车位置 |
| Key 权限 | 地理编码属于 JS API 的插件能力，**Web端(JS API)** 的 Key 就有；不需要再申请 Web 服务 Key |
| 重名地点 | `citylimit:false` + `city:'全国'` 时按名称相似度取第一条，"东站"这类名字可能落到别的城市 |
| 断网 | 用 `CACHE`（落盘到配置）先居中，网络恢复后再解析一次 |

### 4.7 把「时间」标在图上

三种常用做法，按侵入性从低到高：

**(a) 只放在信息窗里**（最常用，也是本程序的做法）：见 4.3，不占屏幕。

**(b) 时间做成标记下方的第二行小字**：把 `buildMarker` 的 `sub` 换成
`速度 · 公里标 · 时间`：

```js
sub.textContent = [speed + ' km/h', 'K' + km, time.slice(11, 19)]
  .filter(Boolean).join(' · ');           // -> 67 km/h · K38.2 · 14:30:00
```

**(c) 时间做成独立文本覆盖物**（想固定显示在角落时）：

```js
const label = new AMap.Text({
  text: 'K19533  14:30:00',
  position: [lon, lat],
  offset: new AMap.Pixel(12, 8),     // 相对锚点偏移，避免压住标记
  style: {
    'background-color': 'rgba(8,14,20,.85)', 'border': '1px solid #2c3e50',
    'border-radius': '3px', 'color': '#d8e6f2', 'font-size': '11px',
    'padding': '1px 5px', 'white-space': 'nowrap'
  }
});
map.add(label);
// 更新：label.setText('K19533  14:31:00'); label.setPosition([lon, lat]);
```

> `AMap.Text` 需要 `plugin=AMap.Text`（或在 `map` 的 `plugins` 里声明）。
> 数量多时优先用 `content` 拼在标记里，(c) 方案的对象数会翻倍。

### 4.8 多车时的优化

| 问题 | 做法 |
|---|---|
| 标记互相压住看不清 | **屏幕坐标避让**（见下） |
| 频繁 `new Marker` 造成卡顿 | 用 `id → marker` 字典复用，只 `setPosition` / `setContent` |
| 轨迹点无限增长 | 抽稀 + 上限（见 4.4，本程序 240 点） |
| 高频推送导致掉帧 | Python 侧节流（本程序 0.25 s），JS 侧只处理增量 |
| 旧标记盖住新标记 | `zIndex` 按最后报文时间递增 |
| 大量标记点击事件重复绑定 | 在创建标记时绑定一次，回调里从 `state[id]` 取最新数据 |

**屏幕坐标避让（避让算法）**——这是 v2.2 解决「标签糊成一团」的核心，二十行就能实现：

```js
const COLLIDE_PX = 52;   // 两个标签中心在这个距离内就算冲突
const MIN_ZOOM   = 11.6; // 小于这个级别直接全部降级

function declutter() {
  // 按 zIndex 降序处理：最新的车先占位，旧的让路
  const ids = Object.keys(markers)
    .sort((a, b) => (state[b].ts || 0) - (state[a].ts || 0));
  const placed = [];

  for (const id of ids) {
    const m  = markers[id];
    const p  = m.getPosition();
    const px = map.lngLatToContainer(p);          // 关键：经纬度 → 屏幕像素

    const hit = px.y < 0 || px.x < 0
      || placed.some(q => Math.abs(q.x - px.x) < COLLIDE_PX && Math.abs(q.y - px.y) < 26);

    const el = m.getContent();                    // 自定义 DOM
    const clash = hit;
    if (clash || map.getZoom() < MIN_ZOOM) el.classList.add('mini');  // 收起副行
    if (clash) el.classList.add('dim');                              // 降透明度
    if (!clash) { el.classList.remove('mini', 'dim'); placed.push(px); }
  }
}

map.on('zoomend', declutter);
map.on('moveend', declutter);
// update() 推送后也调一次 declutter()
```

```css
.mk.mini .sub { display: none; }   /* 只留车次一行 */
.mk.dim       { opacity: .62; }
```

要点：

1. **用 `lngLatToContainer(lnglat)`**，不要自己算墨卡托投影——它是高德提供的「经纬度 → 容器像素」；
   实现里把 `mini`（收副行）与 `dim`（变淡）分开处理：**缩放太小**或**发生冲突**都收副行，
   但只有在**真的冲突**时才变淡——这样缩得很小时孤零零一辆车仍然保持全亮、信息完整；
2. 冲突判断是**轴对齐矩形近似**（x 52 px / y 26 px），比圆距离快且够用；
3. **按最新时间排序**再占位，保证正在跑的车永远优先显示完整信息；
4. 缩放 / 平移结束都要重算，否则放大后标签还是「缩着的」；
5. `mini` / `dim` 只改 class，不改 `content`——避免每帧重建 DOM。

> 车实在太多（同一屏 > 30 辆）时，避让也只能缓解。可以叠加「只显示最近 N 辆」或
> 「按线路过滤」，效果比继续压字号更好。

## 五、本程序与地图页面的数据协议

Python 侧（`map_panel.py`）把列车状态整理成 JSON，通过
`QWebEngineView.page().runJavaScript("window.LBJ.update({...})")` 推给页面。

### 5.1 推送格式

```json
{
  "follow": true,
  "showTrail": true,
  "night": true,
  "focus": null,
  "trains": [
    {
      "id": "19533",
      "train": "K19533",
      "lat": 39.090210,
      "lon": 117.355276,
      "wgsLat": 39.089108,
      "wgsLon": 117.348798,
      "time": "2026-11-24 14:30:00",
      "speed": "67",
      "km": "38.2",
      "route": "津山线",
      "loco": "HXD3C-0093",
      "direction": "下行",
      "category": "快速旅客列车 (160km/h)",
      "trail": [[117.349, 39.089], [117.352, 39.0896]],
      "trailSpan": "3.4 km"
    }
  ]
}
```

- `id` 是**纯数字**车次（`baseTrain`），不是带前缀的 `train`。基础帧先到、长报文
  后补前缀时，用同一个 id 才能复用同一个标记，避免出现两个点；
- `lat` / `lon` 是 **GCJ-02**（已纠偏，用于画点）；
- `wgsLat` / `wgsLon` 是原始 WGS-84（用于信息窗显示）；
- `trail` 也是 GCJ-02，最多 240 个点（按「移动 >6 m 或 间隔 >3 s」抽稀，见 4.4）；
- `trailSpan` 是轨迹累计里程（v2.2 新增，Python 侧按 `111 km/度` 平面估算），
  页面直接显示在信息卡片的「轨迹」一行，`n 个点 · 3.4 km`；
- `night` 是布尔值（v2.1 新增）。页面里只有**值发生变化**时才调 `applyNight()`，
  所以每帧都带上它也不会有额外开销；
- `focus` 只有「定位」动作才带值，普通增量推送为 `null`。**若每次推送都塞车次，
  页面会每 0.25 秒 `setZoomAndCenter` 一次，用户没法手动平移地图。**

### 5.2 页面暴露的接口

| 方法 | 作用 |
|---|---|
| `window.LBJ.update(payload)` | 增量更新列车（新增/移动/删除），顺带处理 `night` |
| `window.LBJ.focus(id)` | 定位到指定列车 |
| `window.LBJ.clear()` | 清空所有标记与折线 |
| `window.LBJ.setTrail(bool)` | 开关轨迹 |
| `window.LBJ.setNight(bool)` | 切换夜间/日间样式 |
| `window.LBJ.isNight()` | 返回当前是否为夜间样式 |
| `window.LBJ.closeInfo()` | 关闭信息卡片（v2.2，卡片右上角 × 调用它） |
| `window.LBJ.resize()` | 容器尺寸变化后调用 |
| `window.LBJ.locked()` | 用户是否手动拖动/缩放过地图（v2.3.1） |
| `window.LBJ.setFollow(bool)` | 开关自动跟随，并清掉手动锁（v2.3.1） |
| `window.LBJ.center()` | 返回当前视图中心 `[lng, lat]`（v2.3.1） |
| `window.LBJ.centerTo(addr)` | 重新地理编码并居中，`addr` 为空则提示未设置（v2.3.1） |

页内样式常量的写法：

```js
var STYLE_DAY   = 'amap://styles/normal';
var STYLE_NIGHT = 'amap://styles/darkblue';
var isNight = true;

function applyNight(on) {
  isNight = !!on;
  if (map) map.setMapStyle(isNight ? STYLE_NIGHT : STYLE_DAY);
}
```

`setMapStyle()` 不会销毁标记与折线，是切换配色的正确做法；不要用
`map.destroy()` 重建，那样会丢掉所有覆盖物并闪一下白屏。

v2.2 起页面里还多了一层 `body.dark` / `body.light` 的 class 切换：`applyNight()` 除了调
`setMapStyle()`，还会改 `document.body.className`，CSS 变量（`--card` / `--text` /
`--accent` / `--border`）跟着换一套，信息卡片、标记副行、提示条都随之变色。
v2.4 起 `_syncMapNight()` 会把两者拉到一致，但仍分两路下发，改任一侧都不需要重建页面。

### 5.3 想接自己的数据？

只要构造同样的 `payload`，在页面里调用 `window.LBJ.update(payload)` 即可；
或按第四节直接用 Marker/InfoWindow API 写自己的渲染逻辑。

## 六、坐标纠偏（WGS-84 → GCJ-02）

LBJ 的经纬度来自车载卫星定位，是 WGS-84；高德底图是 GCJ-02（火星坐标）。
不做纠偏会偏 100~600 米，看起来像“列车跑到路外”。

本程序使用标准偏移算法（`map_panel.wgs84_to_gcj02`）：

```python
from map_panel import wgs84_to_gcj02
lat, lon = wgs84_to_gcj02(39.089108, 117.348798)
# -> (39.09021, 117.355276)
```

只在程序内部使用，不改动 `DecodeResult` 中的原始值，历史库也保存 WGS-84。

## 七、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面提示“尚未配置高德 Key” | `amapKey` 为空 | 配置里填 Key，保存 |
| 提示“高德地图脚本加载失败” | 网络不通 / Key 无效 / 安全密钥缺失 | 先在浏览器打开 `https://webapi.amap.com/maps?v=2.0&key=你的Key` 看返回；补齐安全密钥 |
| 控制台 `INVALID_USER_SCODE` | 没设 `_AMapSecurityConfig`，或密钥不匹配 | 确认安全密钥与 Key 属于同一应用 |
| `USERKEY_PLAT_NOMATCH` | Key 选错服务平台 | 重新申请 **Web端(JS API)** |
| 地图空白但脚本加载成功 | 容器没有高度 | `#map` 必须有明确宽高（本程序已设为 100%） |
| 标记位置偏移几百米 | 直接用了 WGS-84 | 先转 GCJ-02 |
| 地图加载但无标记 | 只收到基础帧 | 等长报文（1234002/1234001），或该车不发长报文 |
| 内嵌地图不显示，提示装 Addons | 只装了 PySide6-Essentials | `pip install PySide6-Addons`，重启程序 |
| 切了界面日间，地图还是深色 | v2.4 起会自动对齐；若仍不对，看日志有没有 `[地图]` 报错 | 点地图卡片「日间」手动切一次；确认 Key 未过期 |
| 点了「夜间/日间」样式没变 | 样式名拼错 / 该样式未开通 | 用 `amap://styles/normal` 与 `amap://styles/darkblue` 这两个免费样式；换其它样式需先在控制台开通 |
| 夜间模式下标签看不清 | 深色底 + 深色标注 | 加大标记字号/描边，或改用日间样式值班 |
| 自己写页面调 `setMapStyle` 报错 | 地图对象还没 `complete` | 放在 `map.on('complete', ...)` 里，或判断 `map` 非空 |
| 车一多标签就叠在一起 | 没有做屏幕坐标避让 | 见 [4.8](#48-多车时的优化)：`lngLatToContainer` + 冲突判断 + `mini`/`dim` |
| 信息窗文字压在底图上看不清 | `isCustom:true` 但没给背景 | 见 [4.3](#43-点击弹出信息窗车次--时间)：不透明 `background` + 圆角 + 阴影 + 小三角 |
| 轨迹折线发毛、点太密 | 每帧都 push 坐标 | 按位移/时间抽稀，并设上限（本程序 240 点） |
| 放大后标签还是「缩着的」 | 只在 `update` 里算避让 | 额外监听 `zoomend` / `moveend` 再算一次 |
| 换了界面主题但地图标记颜色没变 | 标记颜色是写死的 | 由 `theme.py` 的 `mapColors()` 注入 `__MAPCOLORS__`，页面读 `COLOR` 表 |

### 为什么用 setMapStyle 而不是重建地图？

`setMapStyle` 只改底图配色，覆盖物（Marker / Polyline / InfoWindow）全部保留，
切换是瞬时的；`map.destroy()` + 重新 `new AMap.Map()` 会丢掉所有覆盖物、
重新拉瓦片，用户会看到白屏闪一下。本程序按前者实现，所以日夜切换时列车的
标记与轨迹不会消失。

### 离线怎么办？

高德 JS API 必须联网加载脚本和瓦片。无网络时程序会显示提示，但**解码、列表、历史、ETA 不受影响**；
可以用「网页」按钮在高德 App/浏览器中打开最近位置（也需要网络）。
