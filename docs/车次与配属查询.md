# 车次与配属查询

本文说明车次时刻表与机车配属查询的数据来源、通道与更新机制。

---

## 1. 车次查询

| 通道 | 优先级 | 说明 |
|---|---|---|
| RailGo | 首选 | 结构化字段较全，含担当局段、车底配属、车型、始发终到 |
| 12306 | 备选 | 官方时刻表；网络限制时可单独使用 |

设置中可切换「自动（RailGo→12306）/ 仅 RailGo / 仅 12306」。

返回字段：车次、等级、担当路局、担当客运段、车底配属、车型、始发站、终到站、经停站时刻表。

查询为异步执行，不阻塞解码与界面；失败时保留上一次结果并在日志提示。

---

## 2. 机车查询

| 数据 | 来源 | 规模 |
|---|---|---|
| 机车配属号段表 | LBJ_Console（GPL-3.0） | 一万六千余行号段 |
| 机车类型代号表 | LBJ_Console | 车型 → 代号 → 参数 |
| 车型参数表 | 公开资料整理 | 功率、轴式、最高速度、制造厂等 |

两种用法：

1. **已知车型 + 号段** → 查配属局段、制造厂、参数；
2. **已知机车代号** → 解码报文直接给出代号，程序自动映射到车型与名称。

---

## 3. 数据更新

- 设置中提供「检查更新」；
- 更新源为 RailGo / 公开数据仓库，下载后校验行数与型号数，通过才替换；
- 写入用户数据目录，旧文件自动保留 `.bak` 回退；
- 内置快照始终保留，更新失败时继续使用内置数据。
