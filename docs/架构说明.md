## 1. 分层总览

v3.0 起桌面端、安卓端与共享资源在同一个 Git 仓库、同一套 `v3.x` 版本号发布；
桌面端代码收敛在 `desktop/`，安卓端在 `android/`，两端共用的地图页与数据在 `shared/`。

| 目录 | 职责 |
|---|---|
| `desktop/` | 桌面端 Python 工程（PySide6 + QtWebEngine）：入口 `main.py`，打包 `build.py` + `SDR_LBJ.spec` |
| `android/` | 安卓端 Kotlin + Compose 工程；C++/JNI 解码内核在 `app/src/main/cpp/` |
| `shared/` | 共享地图页 `web/railmap.html`、Leaflet 离线副本与 `data/*.csv|json`（两端共用） |
| `docs/` | 全部文档（本文件、用户手册、技术参考、安卓文档、NOTICE 等） |
| `tests/` | pytest 用例（共享数据、车次、地图页、自动更新、路径分层等） |
| `tools/` | `gen_shared_data.py`、`rtl/` 运行时工具、对拍脚本 |
| `dist/` | 打包产物（不入库） |

各版本的行为变化与迁移说明集中在 [更新记录](CHANGELOG.md)，本文只描述**当前**结构。

## 3. 分层职责与依赖方向

| 层 | 目录 | 允许依赖 | 不允许 |
|---|---|---|---|
| 工具 | `utils/` | 标准库 | 任何 Qt / 项目模块 |
| 数据 | `data/` | 标准库、`utils/`、`shared/data` | Qt 控件、界面类 |
| 内核 | `core/` | 标准库、numpy/scipy、`data/` | Qt 界面类 |
| 共享资源 | `shared/` | 无代码依赖（纯数据 + 静态页面） | 引用任何一端代码 |
| 界面基础 | `ui/theme.py`、`ui/widgets.py`、`ui/config_ext.py` | 标准库、PySide6、qfluentwidgets | 业务类 |
| 界面实现 | `ui/components/`、`ui/dialogs/`、`ui/windows/`、`ui/map_*` | 以上全部 + `runtime.py` | 反向依赖 `app.py` |
| 运行时 | `runtime.py` | 以上全部 | 界面实现类 |
| 组装 | `gui.py` | 所有实现模块 | —— |
| 启动 | `app.py` | `gui.py` + `runtime.py` | —— |
| 入口 | `main.py` | `app.py` | —— |

依赖是**单向**的：`runtime → 实现模块 → gui → app → main`，没有环。

`core/` 内部的短链：`rtl_paths` ← `source_stats` ← `usb_direct` ← `decoder`
（`usb_direct` 不能 import `decoder`，否则循环）。

`data/` 内部：`paths` 是底座（谁都能用），`loco_roster` / `updater` 依赖 `paths`，
`updater` 还依赖 `loco_roster.invalidate()`；`train_info` 只依赖标准库。

## 4. 四个关键设计点

### 4.1 共享运行时 `runtime.py`

模块级公共部分（Qt import、控件别名、`UI_SCALE`、`spx()`、`scale_qss()`、
`CONFIG_PATH`/`DB_PATH`/`ICON_PATH`、`FIRST_RUN`、`applyPgTheme()`）都在这里，
实现模块一句 `from cr_lbj.runtime import *` 即可。

- `spx()` / `scale_qss()` 读 `K.scale()`（`ui/widgets.py` 的共享状态），保证拆分后
  所有模块读同一份倍率。
- `SRC_DIR` 取 `__file__` 上两级，即桌面工程目录 `desktop/`（源码运行时配置/历史库/
  图标/配置模板都在这里）；打包后用 `sys._MEIPASS` / `sys.executable`。

### 4.2 GUI 组装层 `gui.py`

实现模块之间不互相 import：`gui.py` 先 `from <模块> import *` 汇入同一命名空间，
再用 `importlib.import_module()` 把聚合后的名字**回填**到各模块（只补不覆盖）。
新增模块必须在 `gui.py` 的导入列表与 `_PART_MODULES` 里各加一行。

### 4.3 共享层 `shared/`：一份数据，两端读

```
shared/web/railmap.html ──┬─→ 桌面：map_host.setHtml(html, baseUrl=shared/web/)
                          └─→ 安卓：WebView file:///android_asset/web/railmap.html

shared/data/*.csv|json ───┬─→ 桌面：desktop/cr_lbj/data/paths.py 解析（用户覆盖层优先）
                          └─→ 安卓：assets/data + filesDir/data（更新写这里）
```

三条硬约定（改动时必须同时满足）：

1. **地图页零构建**：Leaflet 用相对路径引 `vendor/leaflet/`，两端都靠"把整个
   `shared/web` 目录作为页面基准"来解析；桌面端 `baseUrl` 必须是**目录**且以分隔符结尾。
2. **配置注入点固定**：`railmap.html` 里那行 `/*__LBJ_CONFIG_START__*//*__LBJ_CONFIG_END__*/`
   被桌面端替换成 `INJECTED = {...};`；被改掉也不会崩（加载后再 `applyConfig` 兜底）。
   `tests/test_shared_web.py` 会守这个约定。
3. **数据文件只有 `shared/data` 一份**：安卓构建把它加成 assets 源目录，桌面打包把它
   放进 `_MEIPASS/shared/`，`tools/gen_shared_data.py` 是唯一的生成入口。

两条"页面看不到、宿主必须做"的约定（v3.1）：

4. **远程内容放行**：桌面 `map_host.py` 必须显式 `LocalContentCanAccessRemoteUrls = True`
   （同步放开 `LocalContentCanAccessFileUrls`），否则 `file://` 页面发出的瓦片请求被
   QtWebEngine 全部拦截，地图一片灰——这是 v3.0 桌面地图不显示的真实原因。
5. **请求头由宿主加**：天地图 `*.tianditu.gov.cn` 在 `tdtReferer` 非空时附加
   `Referer: https://<tdtReferer>/`；百度 `*.bdimg.com` 固定附加 `Referer: https://map.baidu.com/`；
   **OSM / ORM 不发 Referer，只发可识别的应用 UA**（两家政策要求可识别 UA、禁止伪造来源，
   v3.2.2 起整改）。桌面在 `_TdtRefererInterceptor`（`QWebEngineUrlRequestInterceptor`），
   安卓在 `TileCache.fetch` / WebView 拦截层；页面本身不处理请求头。

页面与宿主的其它契约（`LBJHost.onLayers` / `cacheArea` / `cacheStats`、
`LBJ.setTrainInfo`（v3.2，补车次·机车信息）、`LBJ.centerLatLng` 等）
见 [地图与图源 · 两端契约](地图与图源.md#9-两端契约宿主与页面)。

**数据目录分层**（`data/paths.py`）解决"内置快照只读、更新要可写"：

```
1. CRLBJ_DATA_DIR            （便携/测试）
2. %LOCALAPPDATA%\CR-LBJ-Receiver\data\   （自动更新写这里）
3. exe 同级 shared/data                   （绿色版解压目录）
4. _MEIPASS/shared/data                   （打包内置快照）
5. 仓库根 shared/data                     （源码运行）
```

### 4.4 启动层 `app.py` 与入口 `main.py`

`main()` 负责参数解析、`CoreConfig.load()`、高 DPI 策略、主题、缩放、QApplication
与 `MainWindow`；`main.py` 只有几行，是源码运行与 PyInstaller 共用的唯一入口。

## 5. 构建

### 5.1 桌面端

```bash
python desktop/build.py        # 清理 -> PyInstaller -> 清运行期数据 -> 校验 -> 汇总（仓库根执行）
```

`desktop/build.py` 调 `desktop/SDR_LBJ.spec`，入口 `desktop/main.py`。`cr_lbj` 由 PyInstaller 静态导入收进
PYZ，`hiddenimports` 里显式列出全部实现模块（`gui.py` 动态 import 的兜底），
v3.0/v3.1 新增的 `map_host/config_ext/data_update/ui_threads/query_ui/data.*` 都已登记；
v3.2 的 `ui/info_lookup.py` 由 `main_window.py` 静态导入，随主窗口一并收进 PYZ。

随包数据：`国铁.ico`、`lbj_config.json`、`README.md`、`docs/`、`tools/rtl/`、
**`shared/`（整目录）**。漏了 `shared/web` 地图会显示"缺少地图页面文件"降级面板
（不崩，但没地图）。

### 5.2 安卓端

见 [安卓构建与环境](安卓构建与环境.md)：`gradlew :app:assembleDebug`，`shared/` 通过
assets 源目录进入 APK，`CMAKE` 必须用 pip 版（SDK 自带二进制在本机崩溃）。

## 6. 扩展指引

- 新增**车型参数** → 改 `desktop/cr_lbj/data/loco_info.py`，跑 `python tools/gen_shared_data.py`
  让安卓端同步（`loco_specs.json`）。
- 新增**解码算法 / 信号链** → `desktop/cr_lbj/core/`，不要引 Qt 控件。
- 新增**数据源** → `desktop/cr_lbj/core/` 独立模块，实现 `open/read/close/getDiagnostics`，
  读流时调 `source_stats.recordBlock()`。
- 新增**面板** → `desktop/cr_lbj/ui/components/`，在 `gui.py` 的导入列表与 `_PART_MODULES` 登记。
- 新增**对话框** → `desktop/cr_lbj/ui/dialogs/`，同上登记。
- 新增**地图图源** → 只改 `shared/web/railmap.html` 的 `BASE_SOURCES` / `RAIL_SOURCES`；
  条目必须写清 `coord`（`wgs` / `gcj` / `bd`）与 URL 模板，桌面下拉读 `config_ext.BASE_LAYERS`、
  安卓设置页读 `MAP_BASES`，三处 id/中文名要**逐字同步**（`tests/test_shared_web.py` 会校验）。
  偏移坐标系底图不能叠 WGS-84 铁路图层，页面会自动暂停。
- 新增**第三方数据源（可更新）** → 在 `data/updater.py` 里加一条 URL 与校验函数，
  写入 `paths.user_data_dir()`，并在 `data_manifest.json` 记录 sha/行数/时间。
- 新增**车次数据源** → 在 `data/train_info.py` 里加 `query_xxx()` 并返回同一套字段，
  再在 `query()` 的 `order` 里登记优先级。

> 登记 `gui.py` 时保持"按原文件顺序"：靠后模块可能在导入期用到靠前模块的常量。

## 7. 两端对照（同一功能的落点）

> 桌面侧路径相对 `desktop/cr_lbj/`，安卓侧路径相对 `android/app/src/main/java/.../crlbj/`。

| 功能 | 桌面 | 安卓 |
|---|---|---|
| 地图页 | `ui/map_host.py` + `map_panel.py` | `ui/pages/MapPage.kt` + `data/SharedAssets.kt` |
| 瓦片缓存 / 代拉 | QtWebEngine 磁盘 HTTP 缓存（页面预取） | `core/TileCache.kt`（DiskLruCache，300 MB）+ `shouldInterceptRequest` |
| 车次查询 | `data/train_info.py` + `ui/dialogs/query_ui.py` | `data/TrainInfoClient.kt` + `SettingsPage.kt` 的「查询·数据」分组（原独立查询页已并入） |
| 配属查询 | `data/loco_roster.py` | `data/LocoRoster.kt` |
| 数据更新 | `data/updater.py`（+ `ui/data_update.py`） | `data/DataUpdater.kt` |
| 历史库 | `data/history.py`（SQLite） | `data/LbjDatabase.kt`（Room） |
| 解码内核 | `core/decoder.py`（Python） | `cpp/core/*`（C++，与 Python 1:1，对拍 0 差异） |
