# 地图与图源（v3.0）

> 桌面端与安卓端**共用同一个地图页** `shared/web/railmap.html`（Leaflet 1.9.4，已本地化），
> 所以本文对两端都适用。图源清单直接写在该文件的 `BASE_SOURCES` / `RAIL_SOURCES` 里，
> 改图源只需改那一处，两端同时生效。

## 1. 一句话结论

- **铁路图源** = OpenRailwayMap（WGS-84 栅格瓦片，5 种样式）。
- **底图** = 可选 11 种，分两类坐标系：WGS-84 系（OSM / CARTO / Esri / OpenTopoMap / 天地图）
  与 GCJ-02 系（高德）。
- **只有 WGS-84 底图能与铁路图层叠加**；一旦切成高德，页面会自动关掉铁路图层并提示原因。
- 列车点、轨迹、铁路图层都是 WGS-84，**与 LBJ 长报文里的经纬度同一基准，不需要纠偏**；
  只有在高德底图下才由页面把标记点做 WGS-84 → GCJ-02 加偏。

### 2.1 可达性：**随网络环境变化**，别当成固定事实

同一台机器 2026-11-26 两次实测（相隔约 35 分钟）结论就不一样——代理/线路状态在变：

| 图源 | 03:05 实测 | 03:40 实测 |
|---|---|---|
| 高德 街道 / 卫星 | ✅ 200 | ✅ 200 |
| **Esri 卫星 / 街道** | ❌ TLS 握手失败 | ✅ 200 |
| **OpenRailwayMap** | ❌ TLS 握手失败 | ✅ 200 |
| OSM / CARTO / OpenTopoMap | ❌ | ❌ |
| 天地图域名 | ⚠️ 可达但需有效 tk + Referer 白名单 | 同左 |

所以"当前能用哪张"不要查文档，直接在**当前网络**里试（20 秒出结果）：

```python
import urllib.request, concurrent.futures as cf
UA = {'User-Agent': 'CR-LBJ-Receiver/3.0 (tile-probe)'}
urls = {
 'osm':        'https://tile.openstreetmap.org/6/52/24.png',
 'carto_dark': 'https://a.basemaps.cartocdn.com/dark_all/6/52/24.png',
 'esri_img':   'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/6/24/52',
 'opentopo':   'https://a.tile.opentopomap.org/6/52/24.png',
 'amap':       'https://webrd01.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x=52&y=24&z=6',
 'orm':        'https://a.tiles.openrailwaymap.org/standard/6/52/24.png',
}
def probe(kv):
    k, u = kv
    try:
        r = urllib.request.urlopen(urllib.request.Request(u, headers=UA), timeout=9)
        return k, 'OK %d' % r.status
    except Exception as e:
        return k, 'FAIL %s' % type(e).__name__
with cf.ThreadPoolExecutor(max_workers=8) as ex:
    for k, v in sorted(ex.map(probe, urls.items())):
        print('%-11s %s' % (k, v))
```

**经验规律**：

- 高德几乎总是可达，但它是 GCJ-02 → 与铁路图层互斥（页面会自动关掉铁路图层）；
- **Esri 卫星/街道是 WGS-84**：可达时是"既有底图、又能叠 OpenRailwayMap"的最佳选择；
- OpenRailwayMap 官方瓦片时通时不通，且其条款只允许小规模、公开免费的应用使用；
- OSM / CARTO / OpenTopoMap 是境内最常见的失败项。

### 2.2 底图全挂时应用自己的表现

- 地图页整屏提示「底图瓦片加载失败」，并给两个**一键按钮**：换成 Esri 卫星 / 换成高德街道；
- 桌面端工具栏左侧显示红色「底图不可达，换一张」；
- 换完底图配置会写回（下次启动沿用），不会每次都要重选。

> 高德瓦片"明文无 Key"属于未授权抓取，长期分发有合规风险，正路是高德开放平台授权；
> 本项目只是把它作为"应急底图"选项保留。

### 2.3 天地图 tk 怎么申请

1. 打开 <https://www.tianditu.gov.cn/> → 注册 → 控制台 → 创建应用；
2. 应用类型选 **浏览器端**，填**域名白名单**（不支持通配符；本地 file:// 页面建议填 `localhost` 并用本地服务承载，或改申请服务端类型自建代理）；
3. 拿到 32 位 `tk`，填到 设置/配置 → 地图 → 天地图 Key。

页面用 WMTS 接口拼 XYZ：`TILEMATRIX={z}&TILEROW={y}&TILECOL={x}`，最大 18 级。
未填 tk 时在下拉里选中该底图只会弹提示、不会加载（避免满屏 403 瓦片）。

## 3. OpenRailwayMap 铁路图层

### 3.1 样式

| id | 内容 | 路径 |
|---|---|---|
| `orm_standard`（默认） | 线路、车站、道岔、里程 | `https://{s}.tiles.openrailwaymap.org/standard/{z}/{x}/{y}.png` |
| `orm_maxspeed` | 限速分级着色 | `.../maxspeed/{z}/{x}/{y}.png` |
| `orm_signals` | 信号机与列控 | `.../signals/{z}/{x}/{y}.png` |
| `orm_electrified` | 电气化区段 | `.../electrified/{z}/{x}/{y}.png` |
| `orm_gauge` | 轨距 | `.../gauge/{z}/{x}/{y}.png` |

- 子域 `a/b/c`，最大 zoom 19；瓦片文件是 512×512 但**覆盖范围等同 256px 瓦片**，
  所以 Leaflet 侧保持默认 `tileSize: 256`（我们没设，默认就是 256），不要用
  `tileSize:512 + zoomOffset:-1`，否则与底图错一倍。
- 叠加顺序：底图 < 铁路（pane z=300）< 轨迹（410）< 标记（620）；透明度默认 85%。

### 3.2 使用条款（重要）

OpenRailwayMap 官方瓦片是**非商业公益服务**，其 API 文档要求：

- 只允许"小规模、少量请求"的应用免费使用；
- 应用必须**对公众免费开放**（不得是内部/商用系统）；
- 必须发送**唯一的 User-Agent**，禁止伪造 UA/Referer，禁止预取与批量抓取；
- 官方可**无预警封禁**超量或商用使用者。

本项目是 GPL-3.0 开源、非商业软件，符合其定位；但**如果你要内部部署或商用**，请自建瓦片
（见 §5），不要长期直连官方服务器。

### 3.3 中国覆盖

ORM 的中国数据完全来自 OSM，覆盖不均衡：主要干线通常有线路/车站，`signals`、`maxspeed`
这类需要标注的图层在中国境内**普遍稀疏**，缺数据时该图层就是透明的，属正常现象。
需要准确的信号/限速信息，请自建或看 `maxspeed` 图层在当地的实际情况，别把"没画出来"当 bug。

## 4. 坐标系与偏移（为什么高德不能叠铁路图层）

- OSM / ORM / CARTO / Esri / OpenTopoMap 全是 **WGS-84 + EPSG:3857**，彼此零偏移。
- 高德是国内合规加密的 **GCJ-02**，相对 WGS-84 在中国境内典型偏移 **300–500 m**，随位置变化。
  换算到像素（约北纬 40°）：

  | zoom | 米/像素 | 400 m 偏移 |
  |---|---|---|
  | 12 | 29.3 | ~14 px |
  | 14 | 7.3 | ~55 px |
  | 16 | 1.83 | ~219 px |

  也就是说，在高德底图上叠 WGS-84 铁路瓦片，线会整体"漂"出去几十到两百多像素，
  而且**瓦片栅格无法逐块纠偏**（要做几何 warp，不现实）。

因此实现上是"二选一"：
1. 底图是 WGS-84 → 铁路图层可开，标记直接用原坐标；
2. 底图是 GCJ-02（高德）→ 自动关闭铁路图层，标记点走 `wgs2gcj()` 加偏。

页面的 `LBJ.status().coord` 会返回当前模式（`wgs`/`gcj`），状态栏里也直接写着。

## 5. 自建 / 离线铁路图层（国内推荐）

| 方案 | 做法 | 适用 |
|---|---|---|
| 预生成 MBTiles / PMTiles | 在境外机器或用 CI 跑 ORM 渲染，只导中国范围 `standard`（必要时加 `maxspeed`），z≤12 体积可控，随安装包或按需下载 | 桌面端离线、安卓端可选下载 |
| 自建瓦片服务 | Docker 跑 OpenRailwayMap（hiddewie 方案），放境内 VPS + CDN，App 只连自己的域名 | 多用户长期使用 |
| 抽矢量自绘 | 用 Overpass/osmium 一次性导出 `railway=rail` 等 way 为 GeoJSON，`L.geoJSON` 画线，可按线路走廊裁剪到几百 KB | 只关心固定几条线路 |

接入方式：改 `railmap.html` 的 `RAIL_SOURCES`，把 `url` 换成自己的模板即可（例如
`https://tiles.example.com/orm/{z}/{x}/{y}.png`），坐标基准仍是 WGS-84；`TMS` 方案如果
y 轴翻转不同，需要在模板里 `{-y}` 或改 `L.tileLayer` 的 `tms` 选项。

## 6. 配置项（两端同名）

| 键 | 含义 | 默认 |
|---|---|---|
| `mapBase` | 底图 id | `osm` |
| `mapRail` | 铁路图层 id（`off` = 不显示） | `orm_standard` |
| `mapRailOpacity` | 铁路图层不透明度 0.2–1.0 | 0.85 |
| `mapNight` | 夜间配色 | `true` |
| `mapFollow` | 自动跟随最新列车 | `true` |
| `mapShowTrail` | 显示轨迹 | `true` |
| `mapZoom` | 初始缩放 | `11` |
| `mapCenterLat` / `mapCenterLng` | 默认中心（WGS-84） | 南昌附近 |
| `mapCenterAddress` | 默认中心的显示名（预设城市名） | 空 |
| `tdtKey` | 天地图 tk | 空 |

> v3.0 起 `amapKey` / `amapSecurity` **配置项已移除**（底图全部免 Key），老配置文件里的
> 键在加载时被忽略、保存后自动消失；高德 JS API 与 `高德地图配置手册` 一并下线。
> 只保留"用浏览器打开位置"时的高德 URI 跳转（该功能内部把 WGS-84 转 GCJ-02）。

## 7. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 地图一片灰、右上角状态写「瓦片失败 N」 | 底图域名不可达（国内访问 OSM 常见） | 换 `tdt_*`（配 tk）或 `amap` |
| 铁路图层开了但什么都看不见 | 该地区 OSM 无铁路数据 / 或当前是高德底图被自动关闭 | 看状态栏「铁路」一行；换 OSM 底图再试 |
| 切到高德后铁路图层自己关了 | 设计如此（GCJ 与 WGS 不能混叠） | 要铁路图层就换 OSM 系底图 |
| 天地图选不动、提示要 Key | `tdtKey` 为空 | 配置页填 tk |
| 标记位置看起来偏几百米 | 底图是高德（GCJ），而你在拿它跟 OSM 对比 | 换成 WGS 系底图对比；高德下标记已加偏，与高德自身对齐 |
| 页面白屏 | 极少见：`vendor/leaflet/` 缺文件（打包漏了 `shared/`） | 检查 `shared/web/vendor/leaflet/` 是否随包分发；桌面端看日志里的 `loadFinished` |
