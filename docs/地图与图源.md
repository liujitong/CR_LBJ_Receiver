# 地图与图源

本文说明地图页面的图源清单、坐标系处理与缓存策略。地图页面为 `shared/web/railmap.html`，
桌面端与 Android 端加载同一份文件，因此图源与交互行为完全一致。

---

## 1. 图源清单

| ID | 名称 | 类型 | 坐标系 | 说明 |
|---|---|---|---|---|
| `amap` | 高德 街道（免 Key） | 矢量栅格 | GCJ-02 | 默认底图，国内路网与注记完整 |
| `amap_img` | 高德 卫星（免 Key） | 影像 | GCJ-02 | 卫星影像 |
| `baidu` | 百度 街道（免 Key） | 矢量栅格 | BD-09 | 备用街道图 |
| `baidu_sat` | 百度 卫星（免 Key） | 影像 | BD-09 | 备用影像 |
| `osm` | OSM 标准 | 矢量栅格 | WGS-84 | 国际通用，国内细节较少 |
| `tdt_vec` | 天地图 矢量（CGCS2000） | 矢量栅格 | CGCS2000 | 需要 Key |
| `tdt_img` | 天地图 影像（CGCS2000） | 影像 | CGCS2000 | 需要 Key |

铁路图层：**OpenRailwayMap**（ORM），叠加显示线路走向，支持标准/最高速度/信号/电气化/轨距五种样式。

---

## 2. 坐标系

程序内部统一使用 **WGS-84**：解码得到的经纬度直接以 WGS-84 存储与传递。

| 底图 | 转换 |
|---|---|
| OSM / 天地图 | 不转换（天地图 CGCS2000 与 WGS-84 在本场景下差异可忽略） |
| 高德 | WGS-84 → GCJ-02 |
| 百度 | WGS-84 → BD-09（经 GCJ-02 中转） |

转换在页面内完成（`toMap()` / `fromMap()`）。**铁路图层在偏移坐标系底图上自动暂停**，
因为 ORM 瓦片是 WGS-84，与 GCJ-02/BD-09 底图叠加会出现线路与列车错位。

## 3. 瓦片与缓存

| 项 | 桌面端 | Android |
|---|---|---|
| 缓存介质 | 浏览器 IndexedDB（WebEngine profile） | DiskLruCache（原生代拉） |
| 缓存开关 | 设置 → 地图 → 离线缓存 | 设置 → 地图 → 离线缓存 |
| 缩放级差 | 可配置（默认 ±2 级） | 同 |
| 主动预取 | 「缓存本区域」按钮 | 同 |

规范：

- 请求 UA 为 `CR-LBJ-Receiver/<version>`，可被服务端识别；
- 对 OSM / ORM 遵守其使用政策：**不做批量预取、不伪造 Referer**；
- 缓存命中失败只影响该图层，不会误判"网络不可达"（底图与铁路图层分别统计）。

## 4. 标记与交互

| 元素 | 说明 |
|---|---|
| 列车标记 | 车次 + 方向底色 + 速度/公里标脚注；最新焦点标记高亮 |
| 轨迹 | 按位移 > 6 m 或间隔 > 3 s 抽稀后的折线 |
| 跟随 | 开启后任何新信号都居中到该车；拖动地图只暂停到下一帧 |
| 空状态 | 无坐标时在左下角显示「暂无列车坐标」，不遮挡地图 |
| 图层菜单 | 切换底图与铁路样式；显示瓦片统计与可达性判定 |

---

## 5. 可达性判定

页面按图层分别统计瓦片成功/失败数：

- 只有**底图**连续失败才判定「底图不可达」并提示；
- 铁路图层失败只影响该图层，不弹全屏错误。

这样避免 ORM 偶发不可用时被误判为整体网络故障。
