## 1. 界面结构

**桌面端**：顶部工具栏 + 主区三栏（频谱 / 当前解码 / 地图与信息）+ 底部状态条。

**Android**：底部导航栏五个页签 —— 地图 / 解码 / 信息 / 状态 / 设置。

| 区域 | 桌面端 | Android | 内容 |
|---|---|---|---|
| 频谱 | 左侧上方 | 解码页展开卡片 | 频谱曲线 + 瀑布图 |
| 当前解码 | 中间表格 | 解码页 | 最新解码记录列表与详情 |
| 地图 | 右侧 | 地图页 | 列车位置、轨迹、底图切换 |
| 信息 | 地图下方卡片 | 信息页 | 车次信息、机车信息、近 12 次解码 |
| 状态 | Ctrl+D 仪表板 | 状态页 | 信号、门控、数据流、射频链路指标 |
| 设置 | 设置对话框 | 设置页（菜单式） | 数据源、门控、解码、地图、查询 |

## 2. 数据源与射频

### 三种数据源

| 类型 | 适用场景 | 需要填写 |
|---|---|---|
| **USB 直连** | RTL-SDR 插在本机（桌面）或 OTG 连接（Android） | 无需填地址，程序自动识别设备 |
| **RTL-TCP** | 局域网内有 `rtl_tcp` 服务端 | 主机、端口（默认 1234） |
| **OWRX** | 使用 OpenWebRX 实例 | 主机、端口、profile |

Android 端可在「设置 → 数据源与射频」中保存多套配置并随时切换；切换类型时程序会给出推荐的采样率与增益。

### 关键参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 中心频率 | 821.2375 MHz | LBJ 预警频点 |
| 采样率 | 960 kS/s | 240 kS/s 亦可；USB 直连按 tuner 自动推荐 |
| 带宽 | 35 kHz | 信道滤波带宽 |
| 硬件增益 | 15.7 dB | USB 直连按 tuner 推荐；网络源由服务端决定 |
| PPM 校正 | 0 | 晶振频偏补偿 |
| DC 偏移 | 50 kHz | 直流泄漏抑制 |
| AFC | 启用，上限 8 kHz | 自动频率跟踪 |

**增益建议**：RSSI 稳定在 -60 ~ -40 dB 且不出现饱和（噪声底抬升）为宜。增益过高会让邻近强信号产生互调。

## 3. 门控与 RSSI 阈值

程序只在信号强度高于阈值时才解码，避免持续处理噪声。

| 参数 | 默认 | 说明 |
|---|---|---|
| 打开阈值 | -55 dB | 低于该值不解码 |
| 迟滞 | 4.0 dB | 关闭阈值 = 打开阈值 - 迟滞，避免反复开关 |
| 保持时间 | 700 ms | 信号短暂跌落时继续解码，防止漏掉报文尾部 |

日志中的「探测到下行/上行信号 干扰严重」表示收到了无法解析车次的帧；这类帧会计入上下行干扰统计，不写入历史记录。

## 4. 地图

| 操作 | 效果 |
|---|---|
| 滚轮 / 双指 | 缩放 |
| 拖动 | 平移（跟随进入「暂停」状态） |
| 点击标记 | 弹出该车次信息 |
| 「跟随」 | 自动居中到最新信号的列车；开启后拖动只是临时暂停，下一条报文到达即恢复 |
| 「回中心」 | 回到默认中心（不关闭跟随） |
| 「转到自己位置」 | 定位并居中（桌面需系统定位，Android 需定位权限） |
| 「图层」 | 切换底图与铁路图层 |

底图包含：高德街道/卫星、百度街道/卫星（免 Key）、OSM 标准、天地图矢量/影像。铁路图层为 OpenRailwayMap。

**离线缓存**：在「地图」设置中开启后，浏览过的区域瓦片会缓存到本地；「缓存本区域」可主动预取当前视野（OSM / ORM 因服务条款不支持批量预取）。

## 5. 解码与历史

### 当前解码

显示最新解码记录，双击（Android 长按或点击）打开详情，包含五个页签：

| 页签 | 内容 |
|---|---|
| 解码结果 | 车次、方向、速度、公里标、线路、机车、经纬度、时间 |
| 原始数据 | 原始 BCD 字符串与地址、功能码 |
| BCD | 逐字符解码过程 |
| 解码过程 | 状态机与纠错过程 |
| 纠错码字 | 每个码字的伴随式与纠错位 |

### 历史记录

- 按时间倒序，支持按车次/机车搜索；
- 支持编辑备注、多选删除、清空、导出 CSV；
- 同一车次在去重窗口内只保留质量最高的一条；
- 解析不出车次的帧不计入历史。

**数据位置**：桌面端为 `%LOCALAPPDATA%\CR-LBJ-Receiver\history.db`；Android 为应用私有数据库。

## 6. 车次与配属查询

| 查询 | 输入 | 输出 |
|---|---|---|
| 车次查询 | 车次号（如 `K1001`） | 时刻表、担当局段、车底配属、车型、始发终到 |
| 机车查询 | 车型 + 号段（如 `HXD3C 0921`） | 配属局段、制造厂、车型参数、号段范围 |

数据源：车次走 RailGo → 12306 双通道；机车走本地号段表与车型参数表，可在设置中在线检查更新。

## 7. 常见问题

| 现象 | 排查方向 |
|---|---|
| 收不到任何报文 | 确认频点 821.2375 MHz、采样率与带宽；确认天线与增益；确认门控阈值未过高 |
| 有信号但解不出车次 | 信号弱或干扰大；日志会给出干扰统计；尝试提高增益或更换天线位置 |
| 地图空白 | 底图服务可能不可达；切换其它底图；检查网络或代理 |
| 地图标记不动 | 该车次未更新报文，或信号中断 |
| 历史记录为空 | 只记录成功解析车次的帧；确认门控与信号 |
| Android 无法打开 USB 设备 | 确认 OTG 供电充足、已授权 USB 权限；部分手机需在开发者选项打开「USB 调试（安全设置）」 |
| 安装 APK 报 `INSTALL_FAILED_USER_RESTRICTED` | 解锁屏幕后重试；在开发者选项打开「USB 安装」；或直接把 APK 传到手机点击安装 |
